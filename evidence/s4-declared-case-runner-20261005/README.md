# Declared-case configured execution source

The existing configured driver currently authors one archive/correction/drop
case itself. The supplied `PairedRecallDesign` exports case history additions,
held-out public probes and prospective arm order, but no configured consumer
records those source inputs and both installed arms.

This source batch puts the case and arm operands with that existing design and
scenario. The same configured driver will execute one explicitly selected
prospective trajectory: source input, canonical cut, then the selected arms on
SDK forks of that original cut. Existing observer, saved-agent, checkpoint,
probe and scorer owners retain every measurement. The archive-specific driver
algorithm is replaced; its original evidence stays frozen. Shared source and
summary work will be identified as shared, not independent arm cost.

This draft is source-only. No model/provider/input, original donor, SDK, native
artifact, holder, package or environment access is granted or performed. A
supplied design and runnable source do not approve the USD75/30-pair study.
Configured paired execution and complete S4 acceptance remain unqualified.
