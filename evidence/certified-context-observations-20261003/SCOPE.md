# Original context observation lookup

Mendel owns the backend manifest lookup from main71e15bba. Arendt and Sch
released the wire/index files; Lovelace owns Tree widgets and CLI launch345.
Core549 remains a separate published branch, not part of this change.

WireLog.context_manifests currently decodes every original wire row for CLI
recorded context and visible Tree observation refresh. Silent observations have
no message sequence and currently contribute no certified checkpoint pointers.

Extend the existing sealed checkpoint family with original observation byte
pointers, generated by the existing observation declaration. CertifiedSourceRead
captures their bytes under original custody and lends decoding after release.
Manifest contents remain solely in the original wire. Keep recorded order,
multiple observations, exact historical birth and retained rename semantics.
CLI and ContextInspection use the same WireLog API; no widget cache, new store,
fallback reader, native change or input/replay.

Shared original byte-range capture belongs to the pointer capability and original
read resource. The writer and canonical rebuild already enumerate CheckpointTable
declarations; they must produce the new member together. Deployment requires the
existing quiet certified checkpoint rebuild; do not mutate a live checkpoint or
silently accept its previous schema. Wire, native proof and UNKNOWN are preserved.

Patterns: BOUND-1 (redecoding unrelated raw rows), IMPL-13 (reuse original certified
read/rebuild machinery), IDEN-6 (original incarnation, not mutable selected name).
Before AST includes Core production/tools/tests and installed Toad consumers;
dynamic receiver ambiguity remains explicit. Checks follow the coherent source
change and cover exact pointer reads, rename/name reuse, append and replacement
custody, then the existing installed CLI/Tree path without provider input.

This removes avoidable work. It does not attribute historical terminal-tail
seconds or claim latency acceptance from source reasoning.
