# Separate arm source/summary/workflow producer

Source work in progress. No original-data, SDK, holder, native, provider, input,
build or study operation; USD75/30pairs still unapproved.

The old run owns one source/summary trajectory, forks both probes at each cut,
and lends both arm records one combined clock. The existing runner will instead
use one unchanged zero-input SDK seed and the existing configured_saved_agent
resource separately for each ordered arm. Each arm owns its private wire/USER
publications, source inputs, chronological cuts and selected probe children.
No source/cut/probe completion or workflow clock is shared between the arms.
Common seed preparation remains outside arm receipts and is not split or charged
as independent work. Original fork rows/prefixes and frozen source_delivery
supply matching; original completion and input-set readers decide exclusivity.

One arm algorithm owns rounds, while the existing selected_native_fork and its
retire_selected capability retain source/custody restoration. Clock ends after
original configured owner and inspector cleanup. Current model/settings, case
construction and manual-cut/probe protocol stay the same. Each arm still does
its own cuts, including a full-history constructor if selected: this is not a
new no-compaction baseline or optional policy intervention.

No new store/class/collector, runtime/lifecycle/codec/native change or historical
report repair. Original outputs and UNKNOWN remain immutable. Draft will publish
the whole producer/caller source batch and proportionate authored checks after
implementation; no actual configured execution is claimed or proposed here.
