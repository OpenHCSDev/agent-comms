# Native Pi cold-readiness policy (isolated startup slice)

A native input-ID turn sends only a `get_state` capability challenge until Pi attests the **matching request ID**, successful response, and exact `pi-native-input-v1-live-only` capability. Pi loads/parses the entire saved JSONL before it can answer. The old 5-second challenge wait timed out on a 111,533,315-byte session (`native_preflight_timeout`, `wait_ms=5000`, `exit_code=-15`); no prompt was sent and this failed turn must not be replayed automatically.

The new *preflight-only* budget is 5 seconds through the first 8 MiB, plus 2 seconds for each subsequent started 8 MiB, capped at 35 seconds. At 111,533,315 bytes the bound is 31 seconds. If the session is absent or cannot be stat-ed, use the original 5 seconds. This is an operational liveness allowance, **not** a guarantee that every large file starts. A real timeout still kills/reaps Pi and reports `budget_ms` with existing `elapsed_ms`, `wait_ms`, `spawn_ms`, and `session_bytes` diagnostics. No change to the model, prompt-start, or active-tool deadlines, four cross-process startup leases, release on success/exception/cancellation, prompt send boundary, session writer fence, exact capability check, or owner/goal send fence.

Provider-free evidence (copied Pi matching all seven reviewed native-package module hashes, no prompts, `PI_OFFLINE=1`, no tools/extensions/skills/context files, temporary owner-only agent dir, forced network rejection): `experiments/native_startup_readiness_probe.py` generated a disposable 116,948,280-byte JSONL (95,390 entries) and received a matching capability `get_state` response in 2,159 ms. An isolated temporary copy of a real 113,012,596-byte saved session responded in 1,650 ms; four concurrent *copies* responded in 2,201–2,308 ms. No source session was opened for writing and temporary copies were removed. The 31-second allowance accounts for observed 5-second live timeout under competing load despite these favorable unloaded probe timings; the 35-second hard cap and four startup leases bound aggregate cold preparation. These observations are **not** paid-provider, prompt-delivery, or readiness approval evidence. The probe logs only timing/size/capability, never source content.

Deterministic tests exercise policy boundary/cap, short-session timeout, size-scaled delayed capability followed by a denied send (no prompt), cancellation/reap under an extended preflight, and lease release. Reproduce the provider-free probe only with a separately copied/test Pi package: `python experiments/native_startup_readiness_probe.py COPIED_PI_PACKAGE 111.53`. The optional `--copy SAVED_SESSION` form first copies a session into an owner-only disposable directory, never launches Pi on the source. Do not run this against a live session as `--session` or supply credentials/prompts.
