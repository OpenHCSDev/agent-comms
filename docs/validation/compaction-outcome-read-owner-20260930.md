## Accepted API and source checkpoint

`CompactionJournal.snapshot(path, session_file, incarnation, registry)` requires
the same existing RegistrySnapshot cohort as the caller's source read. It never
constructs the writer. Missing files return an empty snapshot without creating a
directory; existing sources require a regular, single-link rollback-mode SQLite
file. Symlinks including dangling links, WAL and observed inode replacement are
refused. `mode=ro`, query_only and one read transaction preserve concurrent commit
visibility without DDL, fsync, journal initialization or an immutable-file lie.
The existing JournalCustody authority fences the opened observation.

Snapshot.outcomes holds projections referencing ORIGINAL SelectedSummaryAttempt
records, with sequence from SQLite rowid decoded through existing TypedRow.joined.
Identity remains the original SummaryOperationIdentity. The original frozen
incarnation resolves through the supplied registry's canonical alias owner; a
reused name with a different birth does not select the old outcome. No current
PID liveness filter drops historical evidence.

Summary state declarations own text/exclusion. UNKNOWN stays UNKNOWN, including
RetiredUnknown's unchanged truthful projection; failed/refused records expose
their original reasons. Reserved, declined and native-linked summaries add no
parallel body. CommittedOperation owns exact original attempt/source-digest and
decoded native commit evidence; only that richer original link suppresses an
uncertain notice. No read method mints input admission or retry authority.

Each outcome exposes identity, sequence, native_offset, source_revision and
event(). The NoticeTranscript-derived CompactionOutcomeTranscript carries the
original identity and timestamp=None. Full original native/input-proof revision
remains available; require_native_source(path, through_offset) uses the existing
native revision owner and refuses a different path/inode, uncaptured cut or
truncation while accepting genuine later appends. Snapshot.revision is TextDigest
of the scoped original row order/source custody/projected events. Late old
Reserved→UNKNOWN changes below a later row alter the epoch; unrelated sessions
do not. No global DB/WAL mtime, max-ID validity shortcut, revision counter, seen
cache, state mirror or parallel history is created.
