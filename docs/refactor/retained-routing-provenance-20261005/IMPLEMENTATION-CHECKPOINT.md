## Original projection must precede routing carry

Routing carry changes `active_turn.routing`; an old full Thread decoder may
reject that carried member afterward. The original writer therefore acquires
recorded provenance **before mutation**, under its existing bus/registry custody,
through `RecordedRegistryProjection.capture` and original
`RegistryStore._read_unlocked`. The target's generated declaration travels as
the original operation argument; no target application declaration is imported
into the old producer.

The existing transient `RoutingCarryPlan` carries that original observation.
Target preflight strictly decodes and verifies it alongside every original
routing cell before writes. After carry, the installer verifies the original
bus/protected files and existing non-routing registry digest, then binds the
same typed namespace to the **observed** post-image registry revision in its
existing receipt. This records a legitimate declared routing transition; it
does not strip fields, invent a registry, overwrite original acquisition proof,
or ask the old codec to decode target routing. `HistoryArchive` consumes that
post-image observation with the original namespace. Failed attempts and
original preimages remain under the existing stopped disposition.
