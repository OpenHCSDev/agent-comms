**Why:** import checks and versions passed while starting a thread still failed; a run that errored prints output shaped like a result; a unit's agreement proves nothing.

- A report counts only with its artifact. Owner correction: "A run that errored before running is not evidence." Check it collected, executed and counted before citing it.
- A comms or Toad install, pull or migration works only after a real message to a live agent on that machine is answered.
- Before approving a merge, check the inherited behaviour of every new class and every claim in the reply against the final diff.
- Check every review request against the source; refuse or cite the existing code when it is already done or wrong. Units call out the commander's errors with file:line; a correct challenge is credited publicly and never struck.
- An order states the target shape, the owner to extend and the banned slop shapes up front. A GPT unit does exactly what the words say, takes the cheapest reading and offers proof-shaped proofs.
