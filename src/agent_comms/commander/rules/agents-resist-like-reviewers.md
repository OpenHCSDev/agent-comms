When a unit misses, re-explaining does not change what it does next. Instead:
- tighten the order until no room for interpretation is left: exact edits, the owner, banned shapes and a check;
- or move the task, using strikes as the routing signal.

Never assume a unit generalises from one correction. Every claim is still checked against the diff, every time.
